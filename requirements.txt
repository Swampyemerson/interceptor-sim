# stage 1 (pytest tests/ flight/tests/), stage 3 (dashboard drift) and stage 4
# (the --self-test entry points).
#
#   python3 -m venv --system-site-packages .venv
#   .venv/bin/pip install -r requirements.txt
#
# The --system-site-packages flag is NOT optional: gz.transport13 / gz.msgs10 are
# NOT pip-installable. They come from apt (python3-gz-transport13,
# python3-gz-msgs10, Gazebo Harmonic / OSRF "noble" line) and reach this venv
# through the .pth file that flag creates. Six test files import them at
# collection time (see .github/workflows/ci.yml's header for the list and the
# deselect fallback).
#
# Versions are PINNED to what this machine's .venv actually holds (`pip freeze
# --local`, verified 2026-07-25) -- the numbers in docs/ were produced under
# exactly this set.
#

# "Local-.venv extras not in requirements.txt". That inline hack is now DELETED:
